# Wallpapers — organized by Omarchy theme

120 wallpapers sorted into folders matching the built-in [Omarchy](https://omarchy.org)
themes they best fit, based on each image's dominant palette and mood.

To use one, point your theme's `backgrounds/` at the matching folder (or symlink/copy a
file into `~/.config/omarchy/themes/<theme>/backgrounds/`).

| Theme | Count | Vibe it matches |
|-------|------:|-----------------|
| `tokyo-night` | 11 | Deep navy/indigo nights, neon cyberpunk, city glow |
| `nord` | 15 | Cold blue-grey, arctic fog, misty forests, snow |
| `everforest` | 11 | Muted forest greens, woodland, nostalgic nature |
| `osaka-jade` | 13 | Jade/teal backgrounds, dark green |
| `gruvbox` | 14 | Warm retro reds/oranges/mustard, earthy, industrial |
| `ristretto` | 6 | Warm coffee-dark, red/pink creatures on black |
| `kanagawa` | 4 | Japanese ink & woodblock, sakura, sumi-e |
| `rose-pine` | 9 | Dusty rose/mauve, soft pink dawns and dusks |
| `catppuccin` | 6 | Pastel lavender/mauve on dark |
| `catppuccin-latte` | 9 | Light cream/pastel, minimal and airy |
| `matte-black` | 22 | Pure black & white, high-contrast monochrome, minimal |

Sorting is by look, not subject — grouped so any wallpaper in a folder sits comfortably
next to that theme's UI colors. Move anything that doesn't suit your taste.
